## Phase 1 の反映手順案
1. 本番の DB で、照合 CSV の値が今も同じかを確かめる（コピーでは全行一致を確認済み）。
2. 取り込み系のスクリプトがリリース日を元に戻さないかを確かめる。新着の cron は既存の行を変えないことを確認済み。ほかのスクリプトは未確認。
3. リリース日:
   - wrong 88件の `release_date` と `mmdd` を `correct_date` に差し替える（=LOVE の6件は判断ポイント3による）。
   - 照合の記録（元の値・新しい値・根拠 URL・confidence・照合者）を新しい表に残し、元に戻せるようにする。
   - 見込み: 87件の作品が別の日付ページへ移る。
4. デビュー: `debut_artists.csv` を次のように直す。
   - wrong のうち年月日まで分かる340組と運営側の39組は、正しい日付と作品に差し替える。
   - ok の216組と、差し替えた組には `verified` を付ける。
   - 確認済みのものだけを表示する場合、表示は595組・記念日のある日は238日になる。
5. unknown・年だけ・未確認のデビュー情報の表示のしかた（出さないか、「未確認」と分かる形にするか）は、文案と一緒に承認をもらう。
6. `/about` の「データの出典」の追記も、文案を出して承認をもらってから公開する。
